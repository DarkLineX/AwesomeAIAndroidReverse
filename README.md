## AI安卓逆向资料收集


### AI集成与增强套件

- [apktool-mcp-server](https://github.com/zinja-coder/apktool-mcp-server)A MCP Server for APK Tool (Part of Android Reverse Engineering MCP Suites)

- [GhidraMCP](https://github.com/LaurieWired/GhidraMCP)MCP Server for Ghidra

- [ida-pro-mcp](https://github.com/mrexodia/ida-pro-mcp) AI-powered reverse engineering assistant that bridges IDA Pro with language models through MCP.


- [IDA-NO-MCP](https://github.com/P4nda0s/IDA-NO-MCP)Say goodbye to the complex, verbose, and laggy interaction mode of IDA Pro MCP

- [jadx-mcp-server](https://github.com/zinja-coder/jadx-mcp-server)


- [jadx-ai-mcp](https://github.com/zinja-coder/jadx-ai-mcp)Plugin for JADX to integrate MCP server

- [frida-mcp](https://github.com/zhizhuodemao/frida-mcp) 一个用于frida动态调试的mcp工具，支持自定义frida路径和名称端口,自动管理frida


### AI Skills, Prompts & 脚本

- [android-reverse-engineering-skill](SimoneAvogadro/android-reverse-engineering-skill): 为 Claude Code 设计的专用技能，专注于 APK 反编译和自动化的 HTTP API 提取 。

- [ai-reverse-toolkit](zhizhuodemao/ai-reverse-toolkit): 收集整理了用于逆向分析的 AI Skills、规则和提示词，是一个很好的起点 。


- [Deobfuscate-android-app](https://github.com/In3tinct/Androidmeda): 利用本地 LLM (如 LLaMA, DeepSeek) 对混淆的 Android 代码进行反混淆和漏洞检测 。
